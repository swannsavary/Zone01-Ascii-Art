Ce projet consistent a prendre une chaine de caractere et l'afficher en fonction de differant fichier/polisse d'ecriture.

Ce projet ne prend en compte que les caracteres ascii de 32 jusqu'a 128. De plus les "\n" ne sont pas ecrit, mais font sauter une ligne.

Si vous ecrivez deux arguments le deuxieme doit etre soit 1, 2 ou 3 en fonction de la polisse que vous voulez:
1 : standard 
2 : shadow
3 : thinkertoy
